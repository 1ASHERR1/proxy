The page comes back served from nebula, so you keep browsing without leaving.

nebula is a small, self-hosted web proxy — you run it yourself with node bin/unblock.js. It's built for reading static and lightly-scripted sites; logins, heavy web apps and streaming video are out of scope. Use it in line with the rules of whatever network you're on.
